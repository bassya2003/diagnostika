# План пилота Sana Space (этап 0)

**Цель:** проверить главные риски продукта до инвестиций в разработку — доходимость, честность ответов и качество ИИ-синтеза.

## 1. Как раздать ссылку

Прототип — один HTML-файл, для ссылки его нужно разместить на бесплатном хостинге (2 минуты):

1. **Netlify Drop** (рекомендую): зайдите на app.netlify.com/drop → перетащите файл `sana_space_prototype.html`, переименованный в `index.html` (положите его в папку и перетащите папку) → получите ссылку вида `https://xxx.netlify.app`. Бесплатно, нужна регистрация email.
2. Альтернатива: **tiiny.host** — перетащить файл, ссылка сразу, без карты (бесплатно до 7 дней — на пилот хватит).

Важно понимать: данные хранятся в браузере подростка. Результаты вы получаете **файлом**: после Дня 8 у ребенка появляется кнопка «📤 Скачать файл результатов» — он отправляет файл вам в WhatsApp. Эти файлы загружаются в кабинет консультанта (второй HTML-файл) — там вся аналитика.

## 2. Выборка (5–10 человек)

- Возраст 14–18, минимум 2 человека с казахским интерфейсом (проверка языка после вычитки).
- Разные профили: минимум один «не знаю, кем быть», один «все решено» (проверка сопротивления), один записанный родителями (проверка сценария недобровольности).
- Согласие родителей для несовершеннолетних — устно/письменно зафиксировать (для пилота достаточно сообщения в WhatsApp).

## 3. Процедура

- Режим А (честный, 5+ человек): 1 день = 1 модуль, 8 дней, как в продукте. Ваше сообщение-инструкция каждому: «один модуль в день, отвечай честно, в конце скачай файл и пришли мне».
- Режим Б (быстрый, 2–3 человека): пройти за 2–3 дня — проверка, ломается ли диагностика при «запое» (сравните глубину ответов с режимом А).
- После завершения — короткое интервью 10 минут с каждым: что зашло, где скучно, где непонятно, что показалось «про меня», доверил бы такому ИИ.

## 4. Что мерим (по файлам результатов + интервью)

| Метрика | Как считаем | Критерий успеха |
|---|---|---|
| Доходимость | % дошедших до Дня 8 | ≥ 70% |
| Глубина открытых ответов | Медиана длины ответов (слова) в игре, интервью, Мультивселенной | ≥ 15 слов |
| Честность | Ваша экспертная оценка: ответы живые или «социально правильные» | Живые у ≥ 80% |
| Качество синтеза | Вы делаете заключение вслепую по сырым данным → сравниваем с флагами и конфликтами, найденными автоматически | Совпадение по главному конфликту в ≥ 2/3 кейсов |
| Казахская версия | Ошибки/неестественность по фидбеку KZ-участников | Нет блокирующих замечаний |
| Вовлеченность | Вопрос в интервью: «посоветовал бы другу?» (да/нет + почему) | ≥ 70% «да» |

## 5. Решения по итогам

- Все критерии пройдены → пишем ТЗ и запускаем разработку MVP (Сессия 4, этап 1).
- Доходимость < 70% → укорачиваем дни / добавляем геймификацию, повторный мини-пилот.
- Ответы «социально правильные» → усиливаем инструкции и легенды, пересматриваем формулировки.
- Синтез слабый → дорабатываем промпт на собранных реальных профилях (у нас будет золотой датасет из пилота).
