# Настройка: автосбор результатов + живой ИИ

Две независимые надстройки. Можно сделать обе, можно по одной — прототип работает при любом раскладе (если что-то не настроено, он тихо откатывается на старый режим).

---

## Часть А. Автосбор результатов в Google Таблицу (~7 минут, бесплатно)

Результаты подростков будут сами появляться строчками в вашей таблице — без файлов и WhatsApp.

1. Откройте sheets.google.com → создайте таблицу, назовите «Sana Space — результаты».
2. Меню **Расширения → Apps Script**. Откроется редактор кода.
3. Удалите всё в редакторе и вставьте содержимое файла `apps_script_результаты.gs` (из нашего чата). Нажмите 💾.
4. Справа вверху **Развернуть → Новое развертывание**. Тип: **Веб-приложение**. Настройки:
   - «Выполнять от имени» → **Я**
   - «У кого есть доступ» → **Все** (это обязательно — иначе прототип не сможет отправлять)
5. Нажмите «Развернуть», разрешите доступ своему аккаунту (Google покажет предупреждение «приложение не проверено» → Дополнительные настройки → Перейти).
6. Скопируйте **URL веб-приложения** (заканчивается на `/exec`).
7. Откройте `app.html` (прототип) в текстовом редакторе (TextEdit/Блокнот), найдите в самом верху строку `RESULTS_URL: ""` и вставьте URL между кавычек:
   `RESULTS_URL: "https://script.google.com/macros/s/.../exec"`
   Сохраните. (Или пришлите URL мне — вставлю сама.)
8. Перезагрузите папку сайта на Netlify.

**Проверка:** пройдите «⚡ Демо» до конца → на финальном экране появится «✅ Результаты автоматически отправлены» → в таблице появится строка. В колонке «Файл результатов (JSON)» — полные данные: их можно скопировать в файл и загрузить в кабинет консультанта, либо просто читать сводку по колонкам.

Если отправка не удалась (нет интернета), подросток увидит подсказку скачать файл — старый способ остается страховкой.

## Часть Б. Живой ИИ в программе (~15 минут, нужна карта для API)

После настройки в Дне 3 («Твоя история») ИИ будет в реальном времени реагировать на каждый ответ подростка и задавать один углубляющий вопрос — как живой интервьюер. Ответы на эти вопросы попадают в результаты.

**Шаг 1. Получите ключ API**
1. Зарегистрируйтесь на **console.anthropic.com**.
2. Привяжите карту (Billing) и пополните баланс на $5–10 — на пилот хватит с запасом (один подросток ≈ $0.05–0.15).
3. API Keys → Create Key → скопируйте ключ (начинается с `sk-ant-`). Никому его не показывайте и никуда не вставляйте, кроме шага 3.

**Шаг 2. Добавьте файлы на сайт**
Структура папки сайта должна стать такой:

```
sana-site/
├── index.html          (лендинг)
├── app.html            (прототип)
├── privacy.html
├── netlify.toml        ← новый файл из чата
└── netlify/
    └── functions/
        └── chat.js     ← новый файл из чата
```

**Шаг 3. Сохраните ключ в Netlify**
В панели Netlify: **Site configuration → Environment variables → Add a variable**:
- Key: `ANTHROPIC_API_KEY`
- Value: ваш ключ `sk-ant-...`
- Сохранить.

**Шаг 4. Перезагрузите сайт**
Deploys → перетащите папку `sana-site` заново.

**Проверка:** откройте `ваш-сайт.netlify.app/app.html` → День 3 → ответьте на первый вопрос развернуто → должно появиться «⏳ ИИ думает…» и затем реакция с уточняющим вопросом.

**Безопасность:** ключ хранится только на сервере Netlify (в коде сайта его нет — украсть из браузера невозможно). Функция отвечает только на запросы формата программы и режет слишком длинные, подростку передается только текст ответа.

⚠️ Нюанс: если после настройки ИИ не отвечает (в Дне 3 нет реакции) — вероятно, ваш тариф Netlify не подхватил функцию через перетаскивание папки. Напишите мне — переведем деплой на GitHub (тоже бесплатно, +10 минут).
