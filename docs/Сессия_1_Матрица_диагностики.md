# Сессия 1. Матрица диагностики платформы Sana Space

**Версия 1.0 — черновик для валидации методологом (Асель Бапановой)**
Аудитория v1: подростки 14–18 лет. Формат: диагностика по дням. Модель: гибрид (ИИ готовит черновик отчета → консультант подтверждает).

---

## 1. Онбординг (День 0, ~10 минут)

Собираем до старта диагностики. Эти данные не «измеряют» личность — они задают ветвления и контекст для ИИ и отчета.

| Блок | Что спрашиваем | Зачем |
|---|---|---|
| Профиль | Имя, возраст, класс, город, язык интерфейса (каз/рус) | Персонализация, локализация |
| Согласие | Согласие родителя (для <18), контакт родителя | Закон РК о персональных данных |
| **Образовательная траектория** | «Где ты планируешь учиться после школы?» → **(а) Казахстан, (б) за рубежом, (в) рассматриваю оба варианта, (г) пока не знаю** | Ключевая развилка (см. ниже) |
| Уточнение траектории (если б/в) | Какие страны рассматриваешь? Есть ли уже подготовка (IELTS/SAT/языковые курсы)? Кто инициатор — ты или родители? | Реалистичность, «послания» окружения |
| Ограничения | Здоровье, бюджет на обучение, возможность переезда | Вопрос 3 интервью из сценария |
| Опыт профориентации | Проходил ли тесты/программы раньше, что рекомендовали, согласен ли | Вопрос 1 интервью |
| Добровольность | «Ты сам решил пройти программу или тебя записали?» | Флаг сопротивления → ИИ применяет мотивационный сценарий из программы |

**Ветвление по траектории:**

- **Казахстан** → трек ЕНТ: профильные предметы ЕНТ, вузы РК, гранты.
- **За рубеж** → трек международный: IELTS/TOEFL, SAT/A-Levels/Foundation, требования зарубежных программ, стипендии (Bolashak и др.).
- **Оба / не знаю** → диагностика идет одинаково, но в финальном отчете рекомендации по поступлению даются в двух вариантах, а ИИ в синтез-диалоге (День 7) исследует этот вопрос сократовскими вопросами: что привлекает за рубежом, чья это мечта, какие есть реальные возможности.

Траектория влияет **только** на блок «поступление» в отчете — сама диагностика личности от нее не зависит (принципиально: сначала «кто я», потом «где учиться»).

## 2. Матрица «теория → конструкт → шкала → механика»

| # | Теория | Что измеряем | Шкала в отчете | Механика на платформе | День |

ИИ классифицирует формулировки «почему» по трем потребностям | 1 |
| 2 | Деци–Райан | Автономность / компетентность / связанность | /10 каждая | Ситуативные мини-кейсы («выбери, как тебе комфортнее работать») + анализ ответов игры | 1 |
| 3 | ЛУПа (авторская методика) | Любимые области знаний и занятия | 1–10 по каждому пункту | Цифровой бланк ЛУПы (списки из бланка, для подростков). ## 4. Модель скоринга и формат результата

Каждый день пишет результаты в единый JSON-профиль — его получает ИИ-ассистент для синтеза и отчета:

```json
{
  "profile": {"age": 16, "grade": 10, "lang": "kk",
    "track": "abroad|kz|both|undecided",
    "constraints": {"health": "...", "budget": "...", "relocation": true},
    "voluntary": true},
  "mcclelland": {"power": 0.2, "affiliation": 0.3, "achievement": 0.5,
    "passengers_choice": "...", "rejected_roles": ["...", "..."], "quotes": ["..."]},
  "lupa": {"subjects": {"математика": 9, "история": 2}, 
    "activities": {"программировать": 10},
    "extremes_explained": [{"item": "история", "score": 2, "reason": "..."}]},
  "riasec": {"R": 0.55, "I": 0.81, "A": 0.4, "S": 0.2, "E": 0.79, "C": 0.43},
  "gottfredson_antirating": [{"profession": "бухгалтер", "reason": "однообразие цифр"}],
  "values": {"развитие_себя": 33, "духовное_удовлетворение": 33, "креативность": 34,
    "соц_контакты": 31, "престиж": 31, "материальное_положение": 34,
    "достижения": 35, "индивидуальность": 37},
  "schein": {"проф_компетентность": 6, "менеджмент": 8, "автономия": 9,
    "стабильность_работы": 10, "стабильность_жительства": 5, "служение": 6,
    "вызов": 4, "интеграция_стилей": 10, "предпринимательство": 9},
  "narrative": {"childhood_dreams": "...", "family_professions": "...",
    "three_whales": {"create": "...", "learn": "...", "give": "..."},
    "orientation": "productive|consumer"},
  "money": {"start": 300000, "comfort": 1500000, "realistic": true},
  "limiting_beliefs": ["..."],
  "inner_conflicts_hypotheses": ["служение глобально vs неприязнь к рутинной работе с людьми"]
}
```

**Принцип разделения контента и ИИ:** интерпретационные тексты шкал (описания якорей Шейна, ценностей, векторов RIASEC) — фиксированная контент-библиотека на двух языках, методологически выверенная вами один раз. ИИ их не генерирует, а только подставляет. Генерирует ИИ только синтез: связки между диагностиками, внутренние конфликты, «дополнительные комментарии» отчета. Это снижает стоимость, исключает методологические ошибки ИИ и упрощает казахскую локализацию.

Правила синтеза (для промпта ИИ, Сессия 3): вектора отчета = RIASEC × ЛУПа × антирейтинг; основной вектор = максимальное пересечение интересов, потребностей и отсутствия противопоказаний в антирейтинге; обязательный поиск внутреннего конфликта (расхождение между декларируемым и поведенческим — как «служение 7/10 при социальной сфере 0.20»).

## 5. Вопросы на валидацию (ваш ход, Асель)

1. Игра «Пассажиры»: могу ли я использовать 6 ролей из франшизы, или для платформы нужны собственные роли (вопрос прав на ИС Пункта Б — важно прояснить до запуска)?
2. Крайние значения ЛУПы: уточнять каждое (дольше) или максимум 3–4 самых информативных?
3. ~~Рокич: список шкал~~ — решено: 8 шкал /50 из «Исследования ценностей», Шейн — 9 якорей /10 из «Мои потребности (Детский)». Остается вопрос: пришлете ли сами тексты вопросов этих опросников, или составляем заново для платформы (снова вопрос прав ИС)?
4. День 7 «Синтез»: показывать ли подростку предварительный портрет до подтверждения консультантом, или только «спасибо, отчет готовится»?
5. Траектория «за рубеж»: достаточно ли трека «страны + экзамены», или нужна отдельная база зарубежных программ уже в v1 (это заметно усложняет контент)?
6. Не потерял ли я какую-то обязательную диагностику программы (Foresight, стили жизни, матрица выбора из тетради — я отнес их к контентным, а не диагностическим блокам; верно?)
