## ДИЗАЙН-СИСТЕМА (стиль «дорогого агентства»)

- Светлая теплая тема: фон #f7f5f0, текст #161329, приглушенный #645f7e, карточки белые с границей #eceadf, радиусы 22–28px.
- Акцентный градиент из двух цветов (подбери под тему поступления за рубеж, например индиго → небесный), используется в логотипе, кнопках, выделенных словах заголовков.
- Шрифты Google Fonts с поддержкой cyrillic-ext (обязательно — казахские буквы ә, қ, ң, ө, ұ, ү): Montserrat 800/900 для заголовков, Inter 400–800 для текста.
- Три больших размытых цветных «пятна» (blur 90px) фиксированы на фоне, слегка двигаются при скролле (параллакс).
- Анимации: плавное появление секций при скролле (IntersectionObserver + класс .vis), анимированные счетчики цифр, бегущая строка-marquee с ключевыми словами, ротация слова в главном заголовке (плавная смена через opacity каждые ~2.5 сек).
- Обязательные элементы: узкая темная полоса-анонс над шапкой («Набор на поток открыт — места ограничены»); липкая шапка с блюром; CSS-мокап телефона в хиро-секции, парящий с наклоном (внутри — интерфейс продукта: чек-лист этапов поступления с галочками: «Выбор стран ✓, Список вузов ✓, IELTS — в процессе, Мотивационное письмо 🔒, Подача 🔒»); 1–2 парящие карточки-факта вокруг мокапа; на мобильных — закрепленная внизу кнопка WhatsApp.

## ДВУЯЗЫЧНОСТЬ

Каждый текст в двух вариантах внутри `<span data-l="ru">…</span><span data-l="kz">…</span>`; CSS показывает нужный по атрибуту `html[data-lang]`; переключатель РУС/ҚАЗ в шапке, выбор сохраняется в localStorage. Казахский — живой литературный, не калька; пометь его комментарием «черновик до вычитки носителем».

## ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ

- В `<head>` — закомментированные заготовки Meta Pixel и Яндекс.Метрики с местами для ID и инструкцией в комментарии.

- Без внешних библиотек (кроме Google Fonts). Без localStorage-критичных функций, кроме языка. Валидный HTML, весь JS в одном `<script>` внизу.
